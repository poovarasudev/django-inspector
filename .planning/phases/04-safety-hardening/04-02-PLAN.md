### Task 2 — Create `django_inspector/dashboard/auth.py`

**New file:** `django_inspector/dashboard/auth.py`

```python
import ipaddress
import logging
from functools import wraps

from django.http import HttpResponseForbidden
from django.utils.module_loading import import_string

from django_inspector.conf import inspector_settings

logger = logging.getLogger("django_inspector")

_FORBIDDEN_RESPONSE = HttpResponseForbidden("Inspector: access denied")


def _get_client_ip(request) -> str:
    xff = request.META.get("HTTP_X_FORWARDED_FOR")
    if xff:
        return xff.split(",")[0].strip()
    return request.META.get("REMOTE_ADDR", "")


def _ip_allowed(request) -> bool:
    allowlist = inspector_settings.INSPECTOR_DASHBOARD_IP_ALLOWLIST
    if not allowlist:
        return True  # no IP restriction configured
    try:
        client_ip = ipaddress.ip_address(_get_client_ip(request))
        for entry in allowlist:
            try:
                if client_ip in ipaddress.ip_network(entry, strict=False):
                    return True
            except ValueError:
                logger.warning("inspector: invalid IP/CIDR in INSPECTOR_DASHBOARD_IP_ALLOWLIST: %r", entry)
    except ValueError:
        pass
    return False


def _permission_check(request) -> bool:
    perm_path = inspector_settings.INSPECTOR_DASHBOARD_PERMISSION
    if perm_path:
        try:
            checker = import_string(perm_path)
            return bool(checker(request))
        except Exception:
            logger.warning("inspector: INSPECTOR_DASHBOARD_PERMISSION callable failed", exc_info=True)
            return False
    user = getattr(request, "user", None)
    if user is None:
        return False
    return bool(getattr(user, "is_staff", False))


def can_access_dashboard(request) -> bool:
    return _ip_allowed(request) and _permission_check(request)


def inspector_required(view_func):
    """Decorator: require staff (or custom permission) to access inspector dashboard."""
    @wraps(view_func)
    def _wrapped(request, *args, **kwargs):
        if not can_access_dashboard(request):
            return HttpResponseForbidden("Inspector: access denied")
        return view_func(request, *args, **kwargs)
    return _wrapped
```

**Acceptance:** `inspector_required` wraps a view such that:
- Anonymous request (no `user` attribute) → 403.
- Non-staff user → 403.
- Staff user → passes through to original view.
- `INSPECTOR_DASHBOARD_PERMISSION = "myapp.utils.custom_check"` that returns `True` → passes through.
- Body of 403 response does not contain any trace id or event data.

### Task 5 — Create `django_inspector/ignores.py`

**New file:** `django_inspector/ignores.py`

```python
import re
import logging
from functools import lru_cache

logger = logging.getLogger("django_inspector")


@lru_cache(maxsize=1)
def _get_path_patterns_key():
    """Return the settings value as a hashable key for cache invalidation."""
    from django_inspector.conf import inspector_settings
    return tuple(inspector_settings.IGNORE_PATHS or [])


def _compiled_path_patterns():
    patterns = _get_path_patterns_key()
    return [re.compile(p) for p in patterns]


@lru_cache(maxsize=1)
def _compiled_exception_names():
    from django_inspector.conf import inspector_settings
    return frozenset(inspector_settings.IGNORE_EXCEPTIONS or [])


def should_ignore_path(path: str) -> bool:
    try:
        return any(p.search(path) for p in _compiled_path_patterns())
    except Exception:
        logger.debug("inspector: error in IGNORE_PATHS check", exc_info=True)
        return False


def should_ignore_exception(exc: BaseException) -> bool:
    try:
        exc_class = type(exc)
        fqn = f"{exc_class.__module__}.{exc_class.__qualname__}"
        return fqn in _compiled_exception_names()
    except Exception:
        logger.debug("inspector: error in IGNORE_EXCEPTIONS check", exc_info=True)
        return False


def invalidate_ignore_caches() -> None:
    """Clear compiled pattern caches. Call after override_settings in tests."""
    _get_path_patterns_key.cache_clear()
    _compiled_exception_names.cache_clear()
```

**Note on lru_cache and `override_settings`:** `lru_cache(maxsize=1)` on `_get_path_patterns_key()` means the cache holds only one entry keyed on the settings tuple. With `override_settings`, the settings value changes, but the cache doesn't know. Tests must call `invalidate_ignore_caches()` after `override_settings`. Expose this via `from django_inspector.ignores import invalidate_ignore_caches` — document in TESTING.md.

**Acceptance:**
- `IGNORE_PATHS = ["/healthz", "/readyz"]` → `should_ignore_path("/healthz")` returns True, `should_ignore_path("/api/users")` returns False.
- `IGNORE_EXCEPTIONS = ["django.http.Http404"]` → `should_ignore_exception(Http404())` returns True, `should_ignore_exception(ValueError())` returns False.
- `should_ignore_path("/health_check")` with `IGNORE_PATHS = ["/health"]` (prefix regex) → True (re.search matches anywhere in string).

### Task 6 — Gate `IGNORE_PATHS` in middleware

**File:** `django_inspector/middleware.py`

In `__call__`, right after the `is_enabled` check:

```python
from django_inspector.ignores import should_ignore_path

if not inspector_settings.is_enabled:
    return self.get_response(request)

if should_ignore_path(request.path):
    return self.get_response(request)
```

This skips trace id generation, watcher notification, and buffer flush entirely for ignored paths — the request passes through as if the inspector isn't installed.

**Acceptance:**
- A request to `/healthz` with `IGNORE_PATHS = ["/healthz"]` creates zero Events and no trace id on the request object.
- A request to `/api/users/` with `IGNORE_PATHS = ["/healthz"]` still creates Events normally.

## Success Criteria

1. Anonymous GET to `/inspector/` returns 403 with a body that contains no trace ids.
2. Staff user GET to `/inspector/` returns 200.
3. A request to a path matching `IGNORE_PATHS` produces zero Events.
4. A `Http404` exception with `IGNORE_EXCEPTIONS = ["django.http.Http404"]` produces zero `exception.raised` Events.
5. Production startup warning appears in logs when `DEBUG=False` and no explicit permission is configured.

## Risks

- `lru_cache` on ignore patterns doesn't invalidate between test cases that use `override_settings`. Mitigation: expose `invalidate_ignore_caches()` and document in test fixtures.
- `HttpResponseForbidden` returned from a view wrapped by `inspector_required` will itself be intercepted by the exception watcher if the user has `Http404` or auth exceptions. Not a problem — 403 is not an unhandled exception.
- IP detection uses `HTTP_X_FORWARDED_FOR` which can be spoofed. Mitigation: document this; production deployments should use Django's `TRUSTED_PROXIES` / `USE_X_FORWARDED_HOST` configuration.
