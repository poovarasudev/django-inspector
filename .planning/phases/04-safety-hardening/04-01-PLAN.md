### Task 2 — Create `django_inspector/masking.py`

**New file:** `django_inspector/masking.py`

Implement:

```python
_BUILTIN_SENSITIVE_KEYS = frozenset([
    "password", "passwd", "pwd",
    "token", "access_token", "refresh_token",
    "secret", "api_key", "api-key", "x-api-key",
    "authorization", "cookie", "set-cookie",
    "csrfmiddlewaretoken", "csrf_token",
    "session", "sessionid",
    "private_key", "auth",
])

_REDACTED = "***REDACTED***"

# Regex patterns for value scanning (credit-card-shaped and JWT-shaped)
_CC_PATTERN = re.compile(r"\b(?:\d[ -]?){13,19}\b")
_JWT_PATTERN = re.compile(r"[A-Za-z0-9_-]{2,}\.eyJ[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+")


def mask_metadata(metadata: dict) -> dict:
    """
    Return a copy of `metadata` with sensitive values redacted.
    Applies key-based redaction and value-pattern scanning.
    """
    from django_inspector.conf import inspector_settings
    extra_keys = frozenset(k.lower() for k in (inspector_settings.SENSITIVE_KEYS or []))
    all_keys = _BUILTIN_SENSITIVE_KEYS | extra_keys
    return _walk(metadata, all_keys, depth=0)


def _walk(obj, sensitive_keys: frozenset, depth: int):
    if depth > 10:
        return _REDACTED + "_DEEP"
    if isinstance(obj, dict):
        result = {}
        for k, v in obj.items():
            if isinstance(k, str) and k.lower() in sensitive_keys:
                result[k] = _REDACTED
            else:
                result[k] = _walk(v, sensitive_keys, depth + 1)
        return result
    elif isinstance(obj, (list, tuple)):
        walked = [_walk(item, sensitive_keys, depth + 1) for item in obj]
        return type(obj)(walked)
    elif isinstance(obj, str):
        return _scan_value(obj)
    return obj


def _scan_value(value: str) -> str:
    """Replace CC-shaped and JWT-shaped strings with REDACTED."""
    if _JWT_PATTERN.search(value):
        return _REDACTED
    if _CC_PATTERN.search(value):
        return _REDACTED
    return value
```

**Acceptance:** Unit tests cover:
- Dict with `"password"` key → redacted.
- Nested dict `{"user": {"token": "abc"}}` → `{"user": {"token": "***REDACTED***"}}`.
- List containing dicts with sensitive keys → all redacted.
- String value matching CC pattern → redacted.
- String value matching JWT pattern → redacted.
- Non-sensitive keys pass through unchanged.
- Extra `SENSITIVE_KEYS` from settings are respected.
- Depth > 10 truncation.

### Task 3 — Hook masking into `BaseWatcher.record()`

**File:** `django_inspector/watchers/base.py`

In `record()`, import and call `mask_metadata` before `buffer_event`:

```python
def record(self, event_type: str, metadata: dict) -> None:
    if not self._enabled:
        return
    if not inspector_settings.is_enabled:
        return
    trace_id = get_current_trace_id()
    if trace_id is None:
        return
    try:
        from django_inspector.masking import mask_metadata
        masked = mask_metadata(metadata)
    except Exception:
        logger.warning("inspector: masking failed, recording unmasked", exc_info=True)
        masked = metadata
    buffer_event(trace_id, event_type, masked)
```

The fallback on masking failure ensures "never break host request" while logging the problem.

**Acceptance:** After this change, every event from every watcher passes through masking. Verify in tests: a `request.completed` event with a body containing `"password=s3cr3t"` does not have that literal string in the persisted `Event.metadata`.

### Task 4 — Create `django_inspector/sampling.py`

**New file:** `django_inspector/sampling.py`

```python
from contextvars import ContextVar

_sampled_var: ContextVar[bool] = ContextVar("inspector_sampled", default=True)


def set_sampled(sampled: bool) -> None:
    _sampled_var.set(sampled)


def is_sampled() -> bool:
    return _sampled_var.get()


def compute_sampling_decision(request, response) -> bool:
    """
    Compute the final sampling decision given the completed response.
    Always True for error responses and slow requests.
    """
    from django_inspector.conf import inspector_settings
    rate = inspector_settings.SAMPLING_RATE
    if rate >= 1.0:
        return True
    status = getattr(response, "status_code", None)
    if status is not None and status >= 500:
        return True
    slow_threshold = inspector_settings.SLOW_REQUEST_THRESHOLD_MS
    start = getattr(request, "_inspector_start_time", None)
    if start is not None:
        import time
        latency_ms = (time.monotonic() - start) * 1000
        if latency_ms >= slow_threshold:
            return True
    import random
    return random.random() < rate
```

**Acceptance:**
- `compute_sampling_decision(req, mock_500_response)` returns `True` regardless of rate.
- `compute_sampling_decision(req, mock_200_response)` with `SAMPLING_RATE=0.0` returns `False`.
- `compute_sampling_decision(req, mock_200_response)` with `SAMPLING_RATE=1.0` returns `True`.

### Task 5 — Apply sampling in middleware

**File:** `django_inspector/middleware.py`

Modify `__call__` and `_notify_request_end`:

1. At middleware entry, after `is_enabled` check, set `set_sampled(True)` (optimistic).
2. After `_notify_request_end`, compute the final decision and if not sampled, call `clear_buffer()` (before `_flush()`).
3. Expose `request.inspector_sampled` bool.

```python
from django_inspector.sampling import set_sampled, compute_sampling_decision, is_sampled
from django_inspector.storage.flush import clear_buffer

def __call__(self, request):
    if not inspector_settings.is_enabled:
        return self.get_response(request)

    trace_id = generate_trace_id()
    token = set_trace_id(trace_id)
    request.inspector_trace_id = trace_id
    set_sampled(True)

    self._notify_request_start(request)

    try:
        response = self.get_response(request)
        self._notify_request_end(request, response)
        # Post-response sampling gate
        sampled = compute_sampling_decision(request, response)
        set_sampled(sampled)
        request.inspector_sampled = sampled
        if not sampled:
            clear_buffer()
    finally:
        self._flush()
        clear_trace_id(token)

    return response
```

**Acceptance:**
- With `SAMPLING_RATE=0.0`, `Event.objects.count()` stays at 0 after 200 responses.
- With `SAMPLING_RATE=0.0`, a 500 response still creates Events.
- `request.inspector_sampled` is False when discarded, True when captured.

## Success Criteria

1. A request containing `password=s3cr3t` in the POST body results in an `Event.metadata.request_body` that does NOT contain `s3cr3t`.
2. A request with a `Authorization: Bearer eyJ...` header results in an `Event.metadata.request_headers.Authorization` equal to `"***REDACTED***"`.
3. `SAMPLING_RATE=0.0` + 200 response → zero Events created. `SAMPLING_RATE=0.0` + 500 response → Events created.
4. `SAMPLING_RATE=0.0` + `SLOW_REQUEST_THRESHOLD_MS=0` → Events always created (every request is "slow").

## Risks

- Masking import in `record()` adds import overhead on hot path. Mitigate: use a module-level import at the top of `base.py` once Python has warmed up; the `from django_inspector.masking import mask_metadata` inside `record()` becomes a dict lookup on `sys.modules` after first call.
- `clear_buffer()` discards exception events too if `SAMPLING_RATE=0.0` and the exception watcher fired before `_notify_request_end` computed a 500 status. Mitigate: exception events should always be captured. Fix: in `compute_sampling_decision`, also check if exception event was buffered before deciding to discard. Or simpler: always capture if any `exception.raised` event is in the buffer.
