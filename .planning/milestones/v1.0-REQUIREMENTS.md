# Requirements Archive: django-inspector v1.0

**Archived:** 2026-05-03
**Milestone:** v1.0 MVP

## v1 Requirements — All Complete

### Setup & Configuration

- [x] **SETUP-01**: Developer can install via `pip install django-inspector` — ✓ pyproject.toml with setuptools build
- [x] **SETUP-02**: Developer adds `django_inspector` to INSTALLED_APPS and runs `migrate` to set up — ✓ Phase 1
- [x] **SETUP-03**: Watchers auto-discover and register on app startup via AppConfig — ✓ AppConfig.ready() auto-discovery
- [x] **SETUP-04**: Developer can toggle individual watchers via `DJANGO_INSPECTOR` settings dict — ✓ InspectorSettings.watcher_enabled()
- [x] **SETUP-05**: Developer can disable inspector entirely via `INSPECTOR_ENABLED = False` — ✓ InspectorSettings.is_enabled
- [x] **SETUP-06**: Dashboard URL prefix is configurable (default: `/inspector/`) — ✓ DASHBOARD_URL_PREFIX in conf.py

### Tracing

- [x] **TRACE-01**: Each request gets a unique trace_id (UUID) generated in middleware — ✓ generate_trace_id() in InspectorMiddleware
- [x] **TRACE-02**: Trace context is propagated via contextvars (async-safe) — ✓ tracing/context.py with contextvars
- [x] **TRACE-03**: All watcher events reference the originating trace_id — ✓ BaseWatcher.record() injects trace_id

### Request Watcher

- [x] **REQ-01**: Capture HTTP method, path, full URL, query parameters — ✓ RequestWatcher.on_response()
- [x] **REQ-02**: Capture request headers and response headers — ✓ _extract_headers(), response.items()
- [x] **REQ-03**: Capture request body and response body (with configurable size truncation) — ✓ MAX_BODY_SIZE setting
- [x] **REQ-04**: Capture status code and response latency — ✓ time.monotonic() delta
- [x] **REQ-05**: Capture authenticated user, session ID, client IP — ✓ _get_user_info(), _get_session_id(), _get_client_ip()
- [x] **REQ-06**: Inspector's own requests are excluded from recording — ✓ should_ignore_request() checks DASHBOARD_URL_PREFIX

### SQL Watcher

- [x] **SQL-01**: Capture raw SQL query and bound parameters — ✓ _query_wrapper captures sql, params
- [x] **SQL-02**: Capture query execution time — ✓ time.monotonic() wrapper
- [x] **SQL-03**: Capture database alias (for multi-db setups) — ✓ connection.alias
- [x] **SQL-04**: Capture origin file and line number that triggered the query — ✓ _extract_origin() walks call stack
- [x] **SQL-05**: Flag queries exceeding configurable slow threshold (default: 100ms) — ✓ SQL_SLOW_THRESHOLD_MS
- [x] **SQL-06**: Detect N+1 query patterns (repeated queries for same table with different PKs) — ✓ _detect_n_plus_one() (3+ similar)
- [x] **SQL-07**: Detect duplicate identical queries within a single request — ✓ _detect_duplicates() exact match

### Exception Watcher

- [x] **EXC-01**: Capture exception type, message, and full stack trace — ✓ traceback.format_exception()
- [x] **EXC-02**: Capture local variables at each stack frame — ✓ _extract_frames() with _safe_locals()
- [x] **EXC-03**: Capture chained exceptions (`__cause__` and `__context__`) — ✓ _extract_chain()
- [x] **EXC-04**: Link exception to originating request via trace_id — ✓ BaseWatcher.record() injects trace_id

### Storage

- [x] **STOR-01**: Events stored via Django ORM in the application's database — ✓ Event model, flush_events()
- [x] **STOR-02**: Management command to purge events older than configurable duration — ✓ inspector_cleanup --hours --dry-run

### Dashboard

- [x] **DASH-01**: Dashboard served at configurable URL prefix using Django templates + HTMX — ✓ 7 URL patterns, app_name="inspector"
- [x] **DASH-02**: Live feed page showing recent requests with status, method, path, latency — ✓ live_feed view + _live_feed_table.html
- [x] **DASH-03**: Request detail page showing full trace timeline (request → queries → exceptions) — ✓ request_detail with timeline/tabs/waterfall views
- [x] **DASH-04**: Requests list page with filtering by status code, method, path, time range — ✓ requests_list view + filter bar
- [x] **DASH-05**: Queries list page showing all captured SQL with slow/N+1/duplicate indicators — ✓ queries_list with checkbox filters
- [x] **DASH-06**: Query detail page showing SQL, params, execution time, origin code location — ✓ query_detail view
- [x] **DASH-07**: Exceptions list page with exception grouping by type + location — ✓ exceptions_list with type filter
- [x] **DASH-08**: Exception detail page showing stack trace, locals, chained exceptions, request link — ✓ exception_detail with expandable frames
- [x] **DASH-09**: HTMX-powered interactions (polling live feed, loading details without full page reload) — ✓ hx-trigger="every 3s", hx-target, hx-push-url
- [x] **DASH-10**: Clean, responsive UI with self-contained CSS (no external framework dependency) — ✓ inspector-prefixed CSS, responsive at 768px
